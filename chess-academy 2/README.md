# Шахматная академия

Обучающее приложение по шахматам в духе Duolingo: теория, которую сразу проверяешь на доске, дебюты,
дуэль с ботом и разбор твоих партий с chess.com. Проверка ходов и бот работают на Stockfish (в браузере, офлайн).

## Запуск

Нужен Node.js 20+.

    npm install
    npm run dev        # откроется на http://localhost:5173
    npm run build      # продакшн-сборка в папку dist

## Что внутри

- `src/data/openings-white.ts`, `openings-black.ts` — 10 дебютов, у каждого 3–4 варианта (разные ответы соперника):
  линии с объяснением каждого хода и позиции «найди сильнейший ход». Формат описан в `src/data/types.ts`.
  Чтобы добавить дебют или вариант, скопируй существующий объект.
- `src/engine/` — обёртка над Stockfish (Web Worker) и оценка качества хода.
- `src/views/Lesson.tsx` — урок: теория → повтор по памяти → поиск сильнейшего хода.
- `src/views/Duel.tsx` — дуэль: перед каждым ходом нужно оценить угрозы.
- `src/views/Profile.tsx`, `src/lib/chesscom.ts` — подтягивание профиля и партий с chess.com.
- `public/engine/` — файлы Stockfish (lite, single-thread, ~1,8 МБ).

## План на Android / десктоп

Приложение — обычный веб-стек, поэтому: Android через Capacitor (`npx cap add android`),
десктоп-окно через Tauri или Electron.

## Лицензия Stockfish

Stockfish распространяется под **GPL-3.0**. Если выпускать приложение в Play Market, придётся выложить
исходный код приложения под совместимой лицензией (или не использовать Stockfish и заменить движок).
Решить это нужно до публикации.

## Тактика

Раздел «Тактика»: 6 тем (вилка, связка, сквозной удар, вскрытое нападение, мат на последней горизонтали, устранение защитника). В каждой — разбор приёма на демо-доске, признаки, типичная ошибка и 4 задачи от лёгкой к сложной с объяснением. Позиции взяты из партий слабого бота и проверены Stockfish; другой сильный ход, не совпавший с решением, тоже засчитывается после проверки движком. Данные: `src/data/tactics.ts`.

## Эндшпиль

Раздел «Эндшпиль» работает так же, как тактика: разбор на демо-доске, затем задачи с проверкой Stockfish. 6 тем: правило квадрата, оппозиция и ключевые поля, мост Лусены, позиция Филидора, мат ферзём (с ловушкой пата), мат ладьёй. Данные: `src/data/endgames.ts`.

## Серия, уровень, цель дня

На главной показываются серия дней подряд, уровень и дневная цель (30 XP). XP за каждый день хранится в `days` в localStorage; серия не сгорает, пока не закончится день. Логика в `src/lib/storage.ts`, карточка в `src/components/Stats.tsx`.
